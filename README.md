# shkolo-programa-api

Извличане на седмичната програма (HTML снипет) от Школо и запазване в локален файл. Също така предоставя REST API endpoints за получаване на следващ час и сурови данни от програмата.

> ВАЖНО: Използвайте само с вашия собствен акаунт и спазвайте Условията за ползване на платформата. Не вкарвайте или споделяйте идентификационни данни в кода.

## Функционалности
* Влиза програмно (взема CSRF токен + session cookies)
* Изпраща fingerprint полета очаквани от формата за вход
* Извлича XSRF токена от cookies и го използва в следващи AJAX заявки
* Взема HTML програмата за даден ученик / клас / седмица / година
* Запазва сурови HTML данни във файл
* **REST API** за получаване на следващ час и данни от програмата
* **Интелигентно сливане на часове** - комбинира разделени блокове часове (напр. двойни часове)
* **Разпознаване на свободни часове** - идентифицира и маркира свободни периоди
* **Гъвкава проверка на време** - custom time offsets за тестване

## CLI Използване
```bash
node src/index.js --pupil 2500075958 --class-year 2500004752 --week 38 --year 25 --out schedule.html
```

Аргументи (CLI флагове):
* `--pupil` (или env `PUPIL_ID`) – pupil_id query параметър
* `--class-year` (или env `CLASS_YEAR_ID`) – class_year_id
* `--week` – номер на седмицата (ISO седмица която искате). По подразбиране текущата ISO седмица.
* `--year` – двуцифрена година използвана от endpoint-а (напр. 25 за 2025). По подразбиране текущата година % 100.
* `--out` – изходен файл (по подразбиране: schedule.html)

### API Endpoints

#### GET `/sledvashtChas` - Получаване на следващ час

Връща следващия предстоящ час базиран на текущо време или custom време.

**Query Параметри:**
* `pupil` - Pupil ID (или използвайте PUPIL_ID env var)
* `classYear` - Class Year ID (или използвайте CLASS_YEAR_ID env var)
* `week` - Номер на седмицата (по подразбиране: текуща ISO седмица)
* `year` - Двуцифрена година (по подразбиране: текуща година % 100)
* `forceLogin` - Принудително свежо влизане (true/1 или false/0)

**Time Control Параметри:**
* `dayoffset` - Дни за отместване от днес (напр. 1 за утре или -1 за вчера)
* `customhour` + `customminute` - Проверка за часове от конкретно време (напр. customhour=14&customminute=30)
* `houroffset` - Часове за добавяне към текущото време
* `minuteoffset` - Минути за добавяне към текущото време

**Примери:**
```bash
# Следващ час сега
GET /sledvashtChas?pupil=2500075958&classYear=2500004752

# Следващ час утре
GET /sledvashtChas?dayoffset=1

# Следващ час от 14:30 днес
GET /sledvashtChas?customhour=14&customminute=30

# Следващ час 30 минути от сега
GET /sledvashtChas?minuteoffset=30

# Принудително свежо влизане
GET /sledvashtChas?forceLogin=true
```

**Отговор:**
```json
{
  "now": "15.10.2025 г., 14:30:00",
  "checkTime": "15.10.2025 г., 12:30:00", 
  "nextLesson": {
    "start": "13:30",
    "end": "15:05",
    "subject": "Химия", 
    "teacher": "Невенка В. Костова",
    "room": "53",
    "isFreeLesson": false
  },
  "totalLessons": 6,
  "forceLoginUsed": false
}
```

**Пример за свободен час:**
```json
{
  "nextLesson": {
    "start": "08:45",
    "end": "09:30",
    "subject": "ЧК (...)",
    "teacher": "Адриана С. Йорданова (oтсъства)", 
    "room": "45",
    "isFreeLesson": true
  }
}
```

#### GET `/rawSchedule` - Получаване на сурова HTML програма

Връща суровите HTML данни от програмата от Школо.

**Query Параметри:**
* `pupil` - Pupil ID (или използвайте PUPIL_ID env var)  
* `classYear` - Class Year ID (или използвайте CLASS_YEAR_ID env var)
* `week` - Номер на седмицата (по подразбиране: текуща ISO седмица)
* `year` - Двуцифрена година (по подразбиране: текуща година % 100)
* `forceLogin` - Принудително свежо влизане (true/1 или false/0)

**Пример:**
```bash
GET /rawSchedule?pupil=2500075958&classYear=2500004752&week=42
```

**Отговор:**
Сурово HTML съдържание от страницата с програмата в Школо.

### Функционалности

#### Интелигентно сливане на часове
API-то автоматично слива съседни блокове часове които принадлежат към същия час:
- Същ предмет, учител и стая
- Промеждутък между блоковете ≤ 5 минути  
- Резултат: Единичен час с удължено време (напр. 13:30-15:05 вместо два отделни 45-мин блока)

#### Разпознаване на свободни часове
Автоматично разпознава свободни периоди маркирани като "(Свободен час)" и задава `isFreeLesson: true`.

#### Кеширане
- Данните от програмата се кешират за 1 минута за избягване на прекомерни заявки
- Кеш ключът включва ученик, клас, седмица и година
- Използвайте `forceLogin=true` за заобикаляне на кеша

## Бележки
* Ако сайтът промени markup или имена на токени, може да се наложи да коригирате логиката за парсене в `src/index.js`.
* Скриптът нарочно избягва hard-coding на токени; винаги взема свежи.
* Fingerprint стойностите по подразбиране са placeholder-и; реалните стойности обикновено се произвеждат от браузъра.
* Сървърът автоматично обработва сливане на часове и разпознаване на свободни периоди
* API отговорите включват timestamps в български локал

## Обработка на грешки
* Липсващи задължителни параметри връщат 400 Bad Request
* Неуспешни автентификации връщат 500 Internal Server Error  
* Невалидни time параметри се игнорират (fallback към текущо време)
